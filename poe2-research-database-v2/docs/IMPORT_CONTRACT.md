# Import contract

An importer must preserve raw input, emit deterministic normalized output, attach provenance, use stable IDs and never fill missing values from intuition.

Import order:

1. tags and mechanics
2. modifiers
3. skills, supports and spirit gems
4. ascendancies, passives and items
5. interactions
6. patches
7. generated indexes

A patch update must be reviewable as a data diff. Generated files must not be edited manually.
